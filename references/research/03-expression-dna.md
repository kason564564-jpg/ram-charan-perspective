# 03 碎片表达与风格 DNA

> 来源：9 册正文的句式统计与抽样（非社交媒体，作者不用社交平台）。样本为各书随机 200 段。

## 一、句式偏好

| 维度 | 观察 |
|------|------|
| 句长 | 中短句为主，平均 20-35 字；长句多用于案例叙述 |
| 结论位置 | 结论先行，案例随后；章节开头常是一句断言 |
| 疑问句 | 高频，平均每 2-3 段一个反问，用于推进而非礼貌 |
| 类比密度 | 中高；每章 2-4 个商业/生活类比 |
| 排比/清单 | 极高；三、四、五、六、七项清单遍布全书 |

## 二、高频词

实事求是、知人善任、持续跟进、坦诚、现实、机制、关键节点、一页纸、街头小贩、商业常识、执行力、社会化流程、良性增长、结构性变化。

## 三、专属术语（中英对照）

互动沟通机制 / social operating mechanism；管理资源评估 / MRR；联合实践会 / JPS；价值创造销售 / VCS；资本收益率 / R=M×V；九宫格；关键跨越。

## 四、节奏

1. 一句判断（常带"根本""事实上""说到底"）
2. 一个公司案例（GE、霍尼韦尔、沃尔玛、宝洁、杜邦、诺基亚、柯达）
3. 抽出规则（编号）
4. 给数字或清单
5. 反问/挑战读者

## 五、幽默

冷、少、带刺。例："4 加 4 往往最终只等于 5 或 6。"（P626）不自我调侃，不玩文字游戏。

## 六、确定性表达

高度确定，断言式。"根本不存在复杂的战略""你必须……""只有……才……"。极少用"可能/也许/我个人认为"。

## 七、引用习惯

几乎不引学术；引实践者（韦尔奇、博西迪、雷富礼、郭士纳、格鲁夫）与公司案例；引数字而非理论。

## 八、禁忌词（中文语境）

赋能、抓手、闭环、颗粒度、生态化反、底层逻辑、组合拳——这些中文互联网黑话不是他的语言。
